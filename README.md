# ZHY's Blog

> ZHY 的个人博客与知识空间，记录人工智能、机器学习、深度学习、AI Agent、课程学习、软件开发，以及项目、技能、日记、相册和个人成长。

网站入口：[ZHY's Blog](https://www.hustzhy.cn/)

## 网站内容

网站以“学习记录 + 个人展示 + 生活档案”为主线，主要包含：

- **文章**：人工智能、机器学习、深度学习、AI Agent、计算机课程和工程实践笔记。
- **归档、分类与标签**：按时间、知识领域或关键词查找文章。
- **项目**：展示个人项目、技术栈、项目状态、源码和演示链接。
- **技能**：展示 AI、后端、前端、客户端、数据库和常用工具等方向。
- **时间线**：记录学习、项目和成长经历。
- **日记**：保存书籍、电影和生活随笔。
- **相册**：浏览课程、生活与风景照片，支持分组和沉浸式查看。
- **动画、友链与关于**：记录兴趣内容、推荐站点和作者信息。

## 快速浏览

首次进入主页会看到欢迎导航页，可以直接进入文章、归档、相册、日记、项目、技能、时间线或关于页面，也可以点击分类气泡探索不同知识领域。主页还会展示最新内容、继续阅读入口、站点目录和统计信息。

顶部导航和侧栏贯穿整个网站；站内页面支持无刷新跳转，返回主页时可以直接进入主页内容，不必重复经过欢迎页。

## 文章阅读

文章页面提供完整的阅读辅助：

- 支持按年月、主题/标签和热度浏览文章。
- 显示发布日期、分类、标签、字数、预计阅读时间和剩余阅读时间。
- 提供文章目录、章节直达链接、阅读进度和相关文章推荐。
- 支持学习路径、上一篇/下一篇、收藏、标记已读和继续阅读。
- 右下角「阅读笔记」悬浮按钮（自动避让音乐播放器、目录等控件）可打开 Markdown 阅读工作区：电脑与 iPad 可用，手机端隐藏入口；宽屏左右分栏、iPad 竖屏或较窄窗口上下分区，正文与笔记各自滚动，展开与收起带过渡动画，边阅读边记录且不遮挡正文；实时预览、常用格式插入、正文选段摘录、按文章本地自动保存，支持复制和下载 `.md` 备份；`Ctrl/⌘ + S` 保存，`Esc` 收起。笔记不会上传或发送给 AI；浏览器数据被清除后需依靠下载文件保留。
- 文章更新记录和 GitHub 反馈入口方便持续维护内容。
- 支持 QQ、微信二维码、复制链接和系统原生分享。
- 提供免费 GLM AI 阅读助手：生成与复制文章总结、围绕正文追问，支持流式输出和等待动画。
- 点击「规划阅读路线」，按当前文章主题获得由浅入深的站内文章推荐。
- 选中正文文字，可在段落下方进行通俗讲解、举例或翻译；触屏读者也可在文末手动输入选段。
- 文末提供 AI 术语速查与三题复习自测，先独立思考，再按需查看参考思路；支持流式生成、停止、重试和复制。

网站会在当前浏览器保存阅读位置、收藏和已读状态；文章、相册和日记详情页还会显示浏览数据，文章支持点赞与热度。

### 配置 AI 功能

在本地 `.env.local` 中设置 `BIGMODEL_API_KEY`，`BIGMODEL_MODEL` 默认为 `glm-4.7-flash`。Key 仅供 `/api/ai/` 服务端调用使用。重新启动 `npm run dev` 后，公开文章正文上方会显示 AI 阅读助手；点击「生成文章总结」或展开「向 AI 提问」即可使用。提问使用真实流式输出，等待首段文字时显示圆点动画，生成时显示闪烁光标。`Enter` 发送问题，`Shift + Enter` 换行；可以点击「停止生成」取消等待或输出。失败时保留输入和已收到的部分回答，未完成回答不加入下一轮上下文。离开页面时取消请求。

部署到 Vercel、Netlify 或其他支持 Astro 服务端 API 的平台时，在平台环境变量中配置同样的 Key 和模型。GitHub Pages 等纯静态托管可正常构建与阅读，支持 Pagefind 搜索；AI 和服务端统计不可用，需要另行部署服务端。接口只允许 [智谱官方明确免费调用的 GLM-4.7-Flash](https://www.zhipuai.cn/zh/news/148)，不使用依赖赠金的收费模型，也不启用付费工具。设置其他模型会拒绝请求，不会自动切换到 FlashX 等收费型号。免费服务仍受平台并发和速率限制。

总结按文章内容版本缓存 24 小时，每个服务实例最多保存 200 篇；实例重启后重新生成。单个来源每分钟最多发起 8 次请求，此限制和缓存均为实例内存级别。加密文章及线上草稿不会提供给 AI。长文章取开头、中间与结尾节选并在页面提示；对话只发送最近 5 轮上下文。文章和问题仅在读者点击生成或发送时传给智谱，回答不写入文章正文。

本地及部署服务需要能连接 `https://open.bigmodel.cn/api/paas/v4/chat/completions`。接口使用非思考模式以减少等待；认证失败时检查开放平台 Key 和账号状态，请求频繁时稍后重试。

总结与对话的服务端等待上限均为 90 秒，前端为 105 秒；免费模型响应慢时可以主动停止。部署平台自身的函数执行时限仍可能提前中断请求。

## 搜索与发现

输入搜索词后，点击「让 AI 帮我找文章」，即可由看板娘按主题推荐公开文章，并提供可直接打开的站内链接。

网站提供全文搜索，可以查找文章标题、正文、分类和标签。本地开发也可搜索真实公开文章，不再显示演示结果；加密文章和草稿不进入本地搜索。搜索支持：

- `Ctrl + K` / `⌘ + K` 打开搜索。
- `/` 快速聚焦搜索框。
- `↑`、`↓` 选择结果，`Enter` 打开，`Esc` 关闭。

分类页、标签页和侧栏标签面板适合进一步筛选内容；统计区域提供年度、月度、日度趋势以及分类和标签分布图。

页面底部提供本地音乐播放器，支持播放列表、封面、播放控制、进度调整和歌词同步。音乐文件来自网站自身资源，不依赖第三方音乐接口；如果浏览器阻止自动播放，首次交互后即可恢复播放。

## 水豚噜噜看板娘

看板娘是网站中的陪伴式角色，接入同一个免费的 GLM-4.7-Flash，提供简单聊天和网站使用引导。默认角色为水豚噜噜，也可以在信息小窗切换为奶龙；两组角色各有四种已抠图形象，会随页面状态、屏幕尺寸或用户点击变换。它的功能包括：

- 点击角色旁的 💬，与噜噜或奶龙简单聊天、了解网站用法或寻找文章；支持流式输出、等待动画、停止生成和清空对话。
- 聊天窗、信息小窗互斥显示，打开任一窗口时暂停提示气泡。三者统一避让角色，随拖动和窗口大小自动调整，优先放在侧边，空间不足时移到上方或下方；内容过多时可在窗口内滚动。
- 使用透明背景角色图和轻量眨眼动效，不使用漂浮白点，也不进行瞳孔追踪。
- 通过信息小窗选择噜噜/奶龙；点击角色即可切换当前形象，点击对话框可轮换当前角色的专属话语。
- 根据当前页面显示闲逛、思考、阅读、开心、休息和迷路等状态。
- 主题色对话框会显示欢迎语、阅读提示和交互反馈；信息小窗会显示当前角色、形象、页面状态与阅读进度。
- 可以按住角色拖动到任意不遮挡的位置，位置和角色选择会自动保存。
- 支持隐藏、重新显示、触屏操作、键盘焦点和减少动态效果。

所有 AI 功能均按需调用免费的 GLM-4.7-Flash。看板娘对话仅保存在当前页面内存，刷新后清空；每个角色保留最近 5 轮上下文，推荐资料不包含加密文章或草稿。

## 开发验证

建议使用 Node.js 24，与 `package.json` 和 Vercel 服务端运行时保持一致。

- `npm run check`：Astro、TypeScript 和 Stylus 检查。
- `npm run check:runtime`：异常浏览器存储、收藏与阅读进度、搜索竞态和统计接口回归测试。
- `npm run check:notes`：笔记保存与恢复、异常存储、Markdown 预览与导出、阅读工作区定位、阅读进度及组件生命周期测试。
- `npm run check:ai`：免费模型限制、请求校验、流式传输、取消和看板娘布局测试（模拟模型响应）。
- `npm run build`：生成页面与 Pagefind 索引，检查核心功能、站内链接、资源、重复 ID 和章节锚点。

开发服务器忽略 `dist`、`.vercel` 和 `.netlify` 构建输出，避免同时构建时重复刷新。浏览器存储不可用或缓存损坏时，阅读功能自动降级；统计接口超时不会一直锁住点赞按钮。生产环境的浏览量与点赞持久化需要配置 Redis 服务，本地开发使用内存统计。
