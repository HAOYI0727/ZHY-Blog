# ZHY's Blog

> ZHY 的个人博客与知识空间，记录人工智能、机器学习、深度学习、AI Agent、课程学习、软件开发，以及项目、技能、日记、相册和个人成长。

网站入口：[ZHY's Blog](https://www.hustzhy.cn/)

## 网站内容

网站以“学习记录 + 个人展示 + 生活档案”为主线，主要包含：

- **文章**：人工智能、机器学习、深度学习、AI Agent、计算机课程和工程实践笔记。
- **归档、分类与标签**：按时间、知识领域或关键词查找文章。
- **项目**：展示个人项目、技术栈、项目状态、源码和演示链接。
- **技能**：展示 AI、后端、前端、客户端、数据库和常用工具等方向。
- **时间线**：记录学习、项目和成长经历。
- **日记**：保存书籍、电影和生活随笔。
- **相册**：浏览课程、生活与风景照片，支持分组和沉浸式查看。
- **动画、友链与关于**：记录兴趣内容、推荐站点和作者信息。

## 快速浏览

首次进入主页会看到欢迎导航页，可以直接进入文章、归档、相册、日记、项目、技能、时间线或关于页面，也可以点击分类气泡探索不同知识领域。主页还会展示最新内容、继续阅读入口、站点目录和统计信息。

顶部导航和侧栏贯穿整个网站；站内页面支持无刷新跳转，返回主页时可以直接进入主页内容，不必重复经过欢迎页。

## 文章阅读

文章页面提供完整的阅读辅助：

- 支持按年月、主题/标签和热度浏览文章。
- 显示发布日期、分类、标签、字数、预计阅读时间和剩余阅读时间。
- 提供文章目录、章节直达链接、阅读进度和相关文章推荐。
- 支持学习路径、上一篇/下一篇、收藏、标记已读和继续阅读。
- 文章更新记录和 GitHub 反馈入口方便持续维护内容。
- 支持 QQ、微信二维码、复制链接和系统原生分享。

网站会在当前浏览器保存阅读位置、收藏和已读状态；文章、相册和日记详情页还会显示浏览数据，文章支持点赞与热度。

## 搜索与发现

网站提供全文搜索，可以查找文章标题、正文、分类和标签。搜索支持：

- `Ctrl + K` / `⌘ + K` 打开搜索。
- `/` 快速聚焦搜索框。
- `↑`、`↓` 选择结果，`Enter` 打开，`Esc` 关闭。

分类页、标签页和侧栏标签面板适合进一步筛选内容；统计区域提供年度、月度、日度趋势以及分类和标签分布图。

## 外观与语言

读者可以根据习惯调整：

- 亮色、暗色或跟随系统主题。
- 网站主题色。
- Banner、全屏壁纸或纯色背景。
- 桌面/移动端壁纸、壁纸轮播、轻量动效和背景粒子。
- 简体中文、English、繁體中文和日本語界面翻译。

代码块支持高亮、行号、折叠和复制；文章还支持数学公式、Mermaid 图表、提示块和媒体内容。

## 本地音乐

页面底部提供本地音乐播放器，支持播放列表、封面、播放控制、进度调整和歌词同步。音乐文件来自网站自身资源，不依赖第三方音乐接口；如果浏览器阻止自动播放，首次交互后即可恢复播放。

## 水豚噜噜看板娘

看板娘是网站中的陪伴式角色，暂时未连接 AI 模型、联网搜索或聊天服务。默认角色为水豚噜噜，也可以在信息小窗切换为奶龙；两组角色各有四种已抠图形象，会随页面状态、屏幕尺寸或用户点击变换。它的功能包括：

- 使用透明背景角色图和轻量眨眼动效，不使用漂浮白点，也不进行瞳孔追踪。
- 通过信息小窗选择噜噜/奶龙；点击角色即可切换当前形象，点击对话框可轮换当前角色的专属话语。
- 根据当前页面显示闲逛、思考、阅读、开心、休息和迷路等状态。
- 主题色对话框会显示欢迎语、阅读提示和交互反馈；信息小窗会显示当前角色、形象、页面状态与阅读进度。
- 可以按住角色拖动到任意不遮挡的位置，位置和角色选择会自动保存。
- 支持隐藏、重新显示、触屏操作、键盘焦点和减少动态效果。

## 手机与平板体验

网站适配电脑、平板和手机：

- 导航会自动切换为适合小屏幕的菜单和卡片布局。
- 侧栏、目录、标签面板和导航卡片内容过多时，会在面板内部滚动，不会被窗口裁切。
- 文章、项目、技能、相册和统计卡片会随窗口宽度自动排列。
- 相册和文章图片支持触控滑动、缩略图、缩放、方向键和 `Esc` 退出。
- 支持键盘导航、焦点提示、语义化控件和减少动态效果。
